Overview

This project presents a Call Centre Performance Dashboard built using Microsoft Power BI Desktop.
The dashboard provides a comprehensive analysis of call center operations, helping organizations monitor performance, improve efficiency, and enhance customer satisfaction.



🎯 Objective

The main goal of this dashboard is to:

* Track overall call center performance
* Analyze agent productivity
* Monitor customer satisfaction
* Identify operational gaps and improvement areas



📌 Key Metrics (KPIs)

The dashboard highlights important performance indicators:

* Total Calls: 5000
* Total Agents: 8
* Calls Answered: 4054
* Calls Rejected: 946
* % Calls Answered: 81.1%
* % Calls Rejected: 18.9%
* Top Performer (Highest Calls Answered): Jim
* Highest Customer Satisfaction: Dan



📅 Filters & Slicers

* Date Range Filter: Allows users to analyze performance between specific dates
* Month Selection (Jan–Mar): Enables quick monthly comparisons



📊 Visualizations & Insights

1. Calls Resolved vs Not Resolved

* Compares resolved and unresolved calls
* Helps identify service efficiency and issue resolution rate

2. Calls Answered by Agents (Pie Chart)

* Shows contribution of each agent
* Useful for performance comparison and workload distribution

3. Calls Rejected by Agents (Donut Chart)

* Highlights which agents reject more calls
* Helps identify training or performance issues

4. Total Calls by Topic

* Categories include:
    * Streaming
    * Technical Support
    * Payment Issues
    * Admin Support
    * Contract-related queries
* Helps understand customer concerns and demand trends

5. Call Duration by Agent

* Displays total call handling time per agent
* Indicates efficiency and engagement level

6. Total Calls by Month

* Trend analysis for January, February, and March
* Helps identify seasonal patterns and workload changes



📈 Key Insights

* Majority of calls are successfully handled (81.1% answered)
* A noticeable portion (18.9% rejected) indicates scope for improvement
* Certain agents outperform others in both call handling and satisfaction
* Technical and streaming issues dominate customer queries
* Monthly trends show slight variation in call volume
